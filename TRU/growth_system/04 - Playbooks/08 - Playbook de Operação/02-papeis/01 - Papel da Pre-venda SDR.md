# O papel da Pré-venda (SDR)

Material de instrução e treinamento interno

## A pré-venda é o primeiro filtro entre curiosidade e oportunidade real. Abordar com velocidade, qualificar com leitura de contexto, definir perfil e construir relacionamento inicial; tudo isso garante que o funil esteja abastecido com oportunidades genuínas, não apenas com volume.

A pré-venda (SDR/BDR) é crucial para a previsibilidade e crescimento, da Overlens, garantindo que: o funil esteja sempre abastecido com oportunidades reais e qua haja filtro bem aplicado para os perfis dos novos leads para direcionamento adequado para os próximos passos do mesmo na “Jornada do Cliente”. Dessa forma, a Pré-venda é responsável por:

1\. Abordar novos leads imediatamente

O pré-vendedor deve estar disponível, em horário comercial, para assumir o atendimento direto ao lead em até 10min após seu cadastro com o objetivo de melhorar a experiência do cliente e aumentar as chances de conversão. Caso o led se cadastre à noite ou no final de semana, a Pré-venda deve contatá-lo em até 48h úteis.

2\. Filtrar lead (MQLs)

A pré-venda é responsável por filtrar os leads recebidos, assegurando o perfil adequado (fit) com base em critérios estabelecidos (Perfil por nível de consciência). Ela coleta informações estratégicas e alinha expectativas iniciais sobre a solução e o processo. Essas informações garantem melhor aproveitamento na conversão do Closer e alimenta o Marketing com os indicadores corretos para melhorar as campanhas e os MQLs.

3\. Definição de Perfil e próximos passos

A Pré-venda deve avaliar os principais sinais de qualificação do perfil de cada lead para determinar o próximo passo na Jornada do cliente. Caso o lead tem bom perfil de maturidade (MQL), a Pré-venda deve direcioná-lo para uma reunião consultiva com o (a) Closer.  
Caso o lead tenha baixo perfil de maturidade (Não MQL), o mesmo pode ser direcionado diretamente para um produto de entrada (Protocolo 3.2.1, Atlas ou Overpass).  
Essa decisão precisa ser muito treinada e validada pela gestão para ser aplicada com excelência pela Pré-venda.

4\. Engajar e Construir Relacionamento Inicial

É essencial gerar interesse e abrir espaço para a conversa comercial. O pré-vendedor deve criar conexões rápidas e valor imediato, personalizar abordagens com foco nos desafios do lead e usar técnicas de *rapport* para agendar reuniões. A consistência é chave: seguir um processo estruturado de prospecção/qualificação, cumprir cadências de *follow-up* sem ser invasivo e registrar todas as interações no CRM para previsibilidade do funil.

## 5\. Gerir seus Indicadores de Performance (KPIs)

* ### **Taxa de aproveitamento de MQLs → SQLs:** acompanhar, organizar e relatar a conversão de leads recebidos, detalhando: quantidade de leads recebidos em um determinado período, quantos leads responderam abordagem inicial, quantos agendaram reunião, quantos tinha perfil para venda transacional e quantos tinham perfil para venda consultiva. 

* ### **L.R.T (Lead response time):** Tempo de contato inicial com novos leads.    **Taxa de agendamento e No show:** quantidade de reuniões agendadas, no shows, em um determinado período.

6\. Passagem Eficiente para o Closer

O *handoff* (transferência para o *closer*) deve ser claro para garantir fluidez. O pré-vendedor repassa todas as informações, evita retrabalho e alinha expectativas para que o lead chegue à reunião de fechamento preparado, entendendo o próximo passo.

Organização de agenda diária da Pré-venda

**Modelo de agenda sugerida:**

- 9h00 \- 9h30: Daily (camera aberta sempre)  
- 8h30 \- 09h00: Confirmar reuniões  
- 9h00 \- 12h00: Ligações

## SLA: **SDR → Closer**

## 

O SLA (Service Level Agreement \- Acordo de Nível de Serviço) comercial entre SDR e Closer é um documento ou pacto de alinhamento que define as regras, critérios e metas para a passagem de bastão de um "lead" (potencial cliente) entre o pré-vendedor (SDR) e o vendedor de fechamento (Closer). 

Ele serve para garantir que o Closer receba apenas oportunidades com realfit de compra, aumentando a produtividade e evitando desperdício de tempo com leads desqualificados. 

## Regras de Passagem

| Critério | ✔️ Condição Obrigatória |
| :---- | :---- |
| Perfil | Alinhado com ICP (Criativo, Expert, Consultor, Founder, Líder de projeto, Agência, Negócio digital ou Autoridade em construção) |
| Dor/Problema | Problema relevante e caro identificado (ex: escala, posicionamento, oferta, consistência, crescimento) |
| Ambição | Meta clara de 90 dias e visão de crescimento em 12 meses |
| Capacidade de execução | Disponibilidade mínima de 4–6h/semana **OU** time de suporte **OU** histórico de disciplina |
| Autonomia | **Decisor final** (ou co-decisor com poder real) |
| Urgência | Existe **janela crítica (Critical Event)** ou razão estratégica para avançar agora |
| Investimento | Entendimento e aceitação do nível de investimento (ticket Vanguarda ≈ R$12K / ano) |
| Cultura | Perfil com mentalidade de responsabilidade (sem vitimização) |
| Intenção | Interesse **em construção real** (não busca só “aprender mais”) |

## Motivos para NÃO PASSAR

| Causa | Ação |
| :---- | :---- |
| Lead curioso demais | nutrir pelo SDR |
| Sem urgência real | estacionar em nurture com follow quinzenal |
| “Só pesquisando opções” | teste de decisão com SDR antes |
| Falta de autonomia decisória | eliminar ou redirecionar |
| Perfil iniciante demais | direcionar para Overpass |
| Baixa ambição | descartar com elegância |
| Respostas superficiais | não avançar até aprofundar diagnóstico |
| Conversa emocional/sem lógica | travar até a reestruturação de contexto |

## Dados Obrigatórios

| Campo | Descrição |
| :---- | :---- |
| Situação atual | Quem é, contexto, atuação |
| Meta 90 dias | Objetivo concreto |
| Meta 12 meses | Direção de longo prazo |
| Problema caro | O que trava hoje \+ custo do problema |
| Oportunidade | Onde pode crescer rápido |
| CE – Critical Event | Data ou motivo de urgência |
| Autonomia | Confirmação: decide sim/no? |
| Fit | PF ou PJ \+ potencial |
| Sinal de cultura | Maturidade \+ responsabilidade |
| Expectativa | O que espera da Vanguarda |
| Ticket | Lead entendeu o modelo de investimento? (Sim/Não) |
| Indicador | Score final: **A (Premium), B (Bom), C (Nutrir)** |

## SLA de Qualidade do SDR

| Métrica | Meta |
| :---- | :---- |
| Show rate do Closer | **≥ 85%** |
| Taxa de avanço CDA → Proposta | **≥ 70%** |
| Taxa de pipeline qualificado | **100% SQL A ou B** |
| SLA passagem SDR → Closer | **≤ 24h** após qualificação completa |
| Taxa de perda por "desqualificação tardia" | **≤ 10%** (evitar erro de filtro) |
