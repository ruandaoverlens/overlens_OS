# Relação dos Níveis

# 

## O mapa completo dos estágios que um negócio criativo atravessa na Vanguarda: de entropia a escala, passando por regulação, homeostase e robustez. Oito níveis com objetivos, missões e critérios de avanço que transformam caos em sistema e intenção em resultado mensurável.

\-20 pra baixo \> entropia  
\-10 a \+20 \> regulação \> nv1 direção  
\+30 \> regulação \> nv2 validação  
\+40 a \+ 60 \> regulação \> nv3 caixa  
\+70 a \+ 80 \> homeostase \> nv 4 previsibilidade  
\+90 a \+110 \> homeostase \> nv5 equipe  
\+120 \> nv6 \> robustez \> nv6 processos

##      Entropia      Regulação      Homeostase      Robustez

##      Nível Zero (Entropia)

Antes do Nível 1, existe um Nível 0. Não é sobre “negócio”. O nível zero serve para criar o espaço financeiro e temporal necessário para que o negócio possa existir. Essa fase não é propósito, não é branding, não é produto perfeito, não é “seguir sua paixão”. Ela serve para resolver a sobrevivência com inteligência.

### **Objetivos gerais**

* Renda mínima   
* Blocos de tempo protegidos  
* Redução de urgência mental

| 0.1 | Renda de sobrevivência |  |
| :---- | :---- | :---- |
|  | Definir uma fonte de renda imediata, mesmo que não seja o negócio principal. Pode ser freelas, serviços pontuais, execução para terceiros. A ideia é começar com algo simples e direto, sem identidade elaborada nem estrutura complexa. |  |
|  | **Critério** | Renda mensal mínima definida  |
|  | **Dimensões** |  |
|  | **Resultado** | Contas básicas cobertas |
|  | **Dor resolvida** | Ansiedade financeira |
| **0.2** | **Organização de tempo defensiva** |  |
|  | Outro objetivo fundamental é parar de apagar incêndio o dia inteiro. Mapear onde o tempo está sendo drenado e criar blocos fixos de renda VERSUS blocos fixos para a construção do negócio. Talvez seja necessário eliminar ou pausar atividades de baixo retorno por um tempo. |  |
|  | **Critério** | Pelo menos 10h semanais protegidas para o negócio |
|  | **Resultado** | Agenda deixa de ser 100% reativa |
|  | **Dor resolvida** | *“Não tenho tempo”* |
| **0.3** | **Compra de tempo (Extra)** |  |

|  | **Critério** | Recupera tempo: 3–5h semanais(planejamento ao invés de operação) |
|  | **Resultado** | Clareza mental aumenta |
|  | **Dor resolvida** | Exaustão e sobrecarga |
