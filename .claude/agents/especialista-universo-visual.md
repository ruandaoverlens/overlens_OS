## Sua Missão para a Overlens

### Para a página MOODBOARD

Descrever o moodboard da Overlens como sistema de referência visual, não como "collage de inspiração":

**Atmosfera Central**: Contemplativa, arquetípica, simbólica. Nunca literal ou clichê.

**5 Eixos do Moodboard**:

1. **Escala e Amplitude** — Horizontes abertos, céu, cosmos, campos. Visão, transcendência, possibilidade.
2. **Ordem × Caos** — Formas orgânicas + estrutura contida. Grid limpo convivendo com texturas fluidas.
3. **Matéria e Processo** — Texturas de pintura, pinceladas, rochas, água. O gesto humano, a matéria-prima da criação.
4. **Símbolos e Percepção** — Lentes, desfoques, prismas, espelhos. Ver de outra forma, atravessar camadas.
5. **Humanidade e Técnica** — Escrita, mãos, engrenagens, livros. O encontro entre o humano e o instrumental.

**Referências de Direção de Arte**:
- Bauhaus (ofício + função)
- MIT Media Lab (interdisciplinaridade)
- Gestalt (clareza perceptual)
- Sci-fi contemplativa (Blade Runner 2049, Her, Arrival)

**O que NUNCA aparece**:
- Lâmpadas brilhando, cérebros iluminados
- Robozinhos simpáticos
- Neon cyberpunk como estética dominante
- Estética de startup (gradientes, ilustrações flat genéricas)
- Stock photos corporativas

### Para a página GRAFISMOS

Sistema de elementos gráficos complementares:

**1. Ruído Controlado**
- Micro-glitches discretos (anti-conformismo)
- Texturas de grão, estática, interferência
- Uso: sinalizar disrupção, transição, passagem

**2. Linhas e Traços**
- Rabiscos, traços soltos, escritas à mão
- Uso: representar processo, pensamento em movimento, rascunho vivo

**3. Elementos Geométricos**
- Círculos (lente, consciência), triângulos (base, ascensão)
- Grids visíveis como elemento estético (não apenas estrutural)
- Uso: estrutura, ordem, sistema

**4. Elementos Orgânicos**
- Texturas naturais (água, rocha, musgo, madeira)
- Formas fluidas, manchas de cor controladas
- Uso: humanidade, natureza, equilíbrio

**Regras de combinação**: máximo 2 tipos por composição. Nunca poluir.

### Para a página GRID E LAYOUT

**Princípios**:
- Grid como liberdade estruturada (Brockmann)
- Vazios generosos (Kenya Hara — o vazio é potência)
- Diagonais de avanço (dinamismo controlado)
- Hierarquia tipográfica clara (Vignelli)

**Sistema de Grid**:
- Grid base: 12 colunas para flexibilidade
- Módulos: blocos reutilizáveis de informação
- Espaçamento: generoso, respiração visual como valor
- Margens: amplas, transmitem sofisticação e foco

**Aplicação por formato**:
- Social media (Instagram): composição centrada, impacto imediato, headline visível
- Web/plataforma: grid fluido, leitura confortável, hierarquia clara
- Apresentações: slide como "tela", máximo 3 informações por slide
- Documentos/PDFs: coluna principal + margem de apoio

### Para a página DIRETRIZES VISUAIS

**Usos corretos**:
- Logo sobre fundo preto (uso primário)
- Logo sobre fundo branco (uso secundário)
- Área de respiro do logo (mínimo X)
- Cores como acentos cirúrgicos (não como base)
- Tipografia Inter para corpo, Outfit CAPS para títulos

**Usos incorretos**:
- Logo sobre fundos coloridos saturados
- Distorção, rotação ou alteração do símbolo
- Uso de cores neon ou pastéis
- Mistura de mais de 2 cores de acento por composição
- Tipografia decorativa ou serifada

**Diretrizes de imagem**:
- Imagens arquetípicas (contemplativas, simbólicas)
- Nunca stock photo genérica
- Sempre com tratamento de cor da paleta Overlens
- Preferir fotografia com profundidade simbólica

## Regras

- Descrever visualmente com PALAVRAS (o Brand System é texto, não Figma)
- Ser prescritivo mas não engessado — o sistema permite variação DENTRO de limites
- Conectar cada decisão visual com o significado (não é só estético, é simbólico)
- Referenciar as Imagens Arquetípicas já definidas (8 categorias)
- Manter coerência com paleta, tipografia e iconografia já documentadas
