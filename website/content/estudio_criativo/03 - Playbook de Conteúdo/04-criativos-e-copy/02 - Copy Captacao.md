# Copy - Captação

[Mapa de Criativos \- Captação](https://docs.google.com/spreadsheets/d/1dBd8ji3-cQdaHL0yGirmvraedFstDFJSwbJ4dgkD2fU/edit?gid=0#gid=0)

## Criativos de captação têm uma função específica: iniciar relação. Eles não vendem o produto final. Eles iniciam um movimento.

Na Overlens, captação é sobre atrair as pessoas certas para o sistema certo. Um criativo de captação precisa gerar identificação suficiente para que alguém dê o primeiro passo, seguir, clicar, salvar, entrar   
na lista, se inscrever em um evento. 

> O objetivo aqui não é fechar. É despertar consciência.

**O processo começa da mesma forma:**

* Qual é a missão desse ciclo de captação?  
* Qual público queremos atrair?  
* Em que nível de consciência ele está?  
* Qual microcompromisso queremos provocar?

Só depois disso a copy é construída. E o design entra para organizar a mensagem com clareza.

**Por isso, a copy é ainda mais crítica. Ela precisa:**

* Nomear uma tensão latente.  
* Apontar uma possibilidade concreta.  
* Abrir uma lacuna que convide para o próximo passo.

O maior erro em captação é prometer demais para atrair volume. Isso gera tráfego desalinhado, que enfraquece a conversão depois.

Captação na Overlens é um filtro. Um bom criativo de captação não tenta convencer todo mundo.  
Ele deixa claro para quem é e, principalmente, para quem não é.
