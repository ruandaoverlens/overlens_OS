# Trilhas

## Mais de 300 horas de trilhas profundas e interconectadas que desenvolvem habilidades criativas, técnicas, estratégicas e filosóficas. De fundamentos do design a inteligência artificial, de semiótica a mercado internacional. Três eixos, dezenas de trilhas, e novas sendo adicionadas continuamente.

Conjunto de trilhas profundas e interconectadas que desenvolvem habilidades criativas, técnicas, estratégicas e filosóficas. Incluem desde fundamentos da criação até inteligência artificial, negócios criativos, ética, mercado internacional e pensamento nexialista. São mais de 300 horas de conteúdo estruturado, com novas trilhas sendo adicionadas continuamente.

Atualmente as trilhas são divididas em três eixos:

* Criação com IA  
* Mercado Emergente  
* Design e Mensagem

Confira abaixo todas as trilhas:

## Criação com IA

Serve como base conceitual para todas as outras trilhas. É o primeiro contato com a mentalidade criadora da Overlens.  |

|  | Trilha de criação musical com IA baseada em fundamentos. Aborda estrutura musical, emoção, intenção e estilo. Ensina a dirigir a IA como um compositor, não como um botão automático. Foca em música com propósito e identidade. Ideal para trilhas, projetos criativos e experiências imersivas.  |

|  | **Status: Ativa** |
|  | Trilha de escrita profissional de prompts. Ensina lógica, clareza, intenção e estrutura de comunicação com IAs. Vai além de templates prontos. Desenvolve pensamento estratégico aplicado à linguagem. Base para as trilhas de IA.  |
|  | **LLMs** |
|  | **Status: Ativa** |
|  | Trilha focada no uso prático e estratégico de Large Language Models. Ensina como pensar, conversar e extrair valor real dos LLMs. Trabalha limitações, vieses e boas práticas. Ajuda a usar IA como extensão cognitiva. Ideal para criadores e estrategistas.  |
|  | **Search** |
|  | **Status: Planejamento** |

|  | **Agentes** |
|  | **Status: Planejamento** |
|  | Trilha de criação e uso de agentes de IA. Ensina conceitos, arquitetura e lógica de agentes especializados. Mostra como delegar tarefas cognitivas à IA. Foca em produtividade criativa e estratégica. Base para automações inteligentes.  |
|  | **Synthetic** |

|  | **Ethos** |
|  | **Status: Em Desenvolvimento** |
|  | Trilha sobre ética da criação. Aborda responsabilidade, impacto e consequências do ato criativo. Discute tecnologia, IA e poder criativo de forma crítica. Ajuda a criar com consciência e intenção. Fundamental para criadores do futuro.  |

## Design e Mensagem

|  | Sandbox |
| :---- | :---- |
|  | **Status: Ativa** |
|  | Trilha de fundamentos do design visual. Trabalha princípios básicos de forma prática. Serve como base para trilhas mais profundas. Ideal para iniciantes ou reciclagem de fundamentos. Introduz linguagem visual de forma clara. |
|  | **Idea** |
|  | **Status: Ativa** |
|  | Trilha de filosofia da criação. Explora Platão, ciência da criatividade, Vilém Flusser e o conceito de múltiplas lentes. Trabalha inteligência visual e fundamentos do design. Desenvolve pensamento abstrato e criativo. Base conceitual profunda. |
|  | **Design Thinking** |
|  | **Status: Ativa** |
|  | Trilha da metodologia universal de design. Apresenta o diamante duplo. Trabalha empatia, ideação e prototipação. Aplica design à resolução de problemas. Essencial para projetos complexos. |
|  | **Gestalt** |
|  | **Status: Ativa** |
|  | Trilha profunda sobre fundamentos das formas. Aborda psicologia da percepção, gestalt, geometria e tipografia. Trabalha níveis fisiológicos, culturais e individuais da percepção. Conteúdo de nível acadêmico. Essencial para designers e criadores visuais. |
|  | **Chrome** |
|  | **Status: Ativa** |
|  | Trilha avançada sobre cores. Explora neurociência, retina, cérebro e percepção cromática. Aborda harmonia, psicologia e estratégia das cores. Inclui história e métodos clássicos. Conteúdo de nível pós-graduação. |
|  | **Layout** |
|  | **Status: Ativa** |
|  | Trilha de composição gráfica. Parte do grid modular até sistemas avançados. Trabalha estrutura, ritmo e equilíbrio visual. Aplica composição em contextos reais. Base para design editorial, digital e branding. |
|  | **Signal** |
|  | **Status: Ativa** |
|  | Trilha de semiótica aplicada. Aborda Saussure, Peirce, Jung, Plutchik e McLuhan. Trabalha storytelling visual, arquétipos e retórica. Foca na construção de significado. Essencial para comunicação estratégica. |
|  | **Genoma** |
|  | **Status: Ativa** |
|  | Trilha de criação do núcleo da marca. Trabalha propósito, atributos, virtudes e arquétipos. Usa roteiro de marca estruturado. Define identidade profunda. Base para branding consistente. |
|  | **Verbarium** |
|  | **Status: Ativa** |
|  | Trilha de identidade verbal. Explora território de palavras, naming e vocabulário. Trabalha arquitetura de marca e manifesto. Dá voz coerente à marca. Essencial para posicionamento narrativo. |
|  | **Guidelines** |
|  | **Status: Ativa** |
|  | Trilha de criação de universos visuais. Ensina construção de identidades completas. Trabalha símbolos, cores, tipografia e grafismos. Estrutura sistemas visuais consistentes. Finaliza o ciclo do branding. |
