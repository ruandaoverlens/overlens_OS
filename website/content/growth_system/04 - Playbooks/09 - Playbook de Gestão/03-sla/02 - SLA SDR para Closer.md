# SLA: SDR → Closer

## O filtro que separa curiosidade de intenção real. Só avançam para o closer leads com fit confirmado, contexto estratégico completo e maturidade de decisão. Cada critério aqui protege o tempo da operação e eleva a qualidade de cada reunião que acontece.

Garantir que só avancem para o closer leads com FIT REAL, contexto estratégico completo e intenção madura de decisão, evitando perda de tempo com curiosos e indecisos.

## Escopo

\- SDR realiza diagnóstico inicial.  
\- Leads só viram SQL se atenderem aos critérios de ICP \+ interesse real.

## Responsabilidades SDR: 

\- Fazer no mínimo {X} tentativas de contato por lead.  
\- Aplicar checklist de qualificação (ex: BANT).  
\- Passar para Closer apenas SQLs que marcaram reunião confirmada.

## Responsabilidades Closer:

\- Assumir SQLs enviados pelo SDR e que conectaram em reunião  
\- Atualizar status no CRM.

### Indicadores de Performance (KPIs)

\- Taxa de conversão SQL → Oportunidade.  
\- No-show rate (reuniões desmarcadas ou não comparecidas).  
\- Feedback do Closer sobre qualidade dos SQLs.

## Regras de Passagem

| Critério | ✔️ Condição Obrigatória |
| :---- | :---- |
| Perfil | Alinhado com ICP (Criativo, Expert, Consultor, Founder, Líder de projeto, Agência, Negócio digital ou Autoridade em construção) |
| Dor/Problema | Problema relevante e caro identificado (ex: escala, posicionamento, oferta, consistência, crescimento) |
| Ambição | Meta clara de 90 dias e visão de crescimento em 12 meses |
| Capacidade de execução | Disponibilidade mínima de 4–6h/semana **OU** time de suporte **OU** histórico de disciplina |
| Autonomia | **Decisor final** (ou co-decisor com poder real) |
| Urgência | Existe **janela crítica (Critical Event)** ou razão estratégica para avançar agora |
| Investimento | Entendimento e aceitação do nível de investimento (ticket Vanguarda ≈ R$12K / ano) |
| Cultura | Perfil com mentalidade de responsabilidade (sem vitimização) |
| Intenção | Interesse **em construção real** (não busca só “aprender mais”) |

## Motivos para NÃO PASSAR

| Causa | Ação |
| :---- | :---- |
| Lead curioso demais | nutrir pelo SDR |
| Sem urgência real | estacionar em nurture com follow quinzenal |
| “Só pesquisando opções” | teste de decisão com SDR antes |
| Falta de autonomia decisória | eliminar ou redirecionar |
| Perfil iniciante demais | direcionar para Overpass |
| Baixa ambição | descartar com elegância |
| Respostas superficiais | não avançar até aprofundar diagnóstico |
| Conversa emocional/sem lógica | travar até a reestruturação de contexto |

## Dados Obrigatórios

| Campo | Descrição |
| :---- | :---- |
| Situação atual | Quem é, contexto, atuação |
| Meta 90 dias | Objetivo concreto |
| Meta 12 meses | Direção de longo prazo |
| Problema caro | O que trava hoje \+ custo do problema |
| Oportunidade | Onde pode crescer rápido |
| CE – Critical Event | Data ou motivo de urgência |
| Autonomia | Confirmação: decide sim/no? |
| Fit | PF ou PJ \+ potencial |
| Sinal de cultura | Maturidade \+ responsabilidade |
| Expectativa | O que espera da Vanguarda |
| Ticket | Lead entendeu o modelo de investimento? (Sim/Não) |
| Indicador | Score final: **A (Premium), B (Bom), C (Nutrir)** |

## SLA de Qualidade do SDR

| Métrica | Meta |
| :---- | :---- |
| Show rate do Closer | **≥ 85%** |
| Taxa de avanço CDA → Proposta | **≥ 70%** |
| Taxa de pipeline qualificado | **100% SQL A ou B** |
| SLA passagem SDR → Closer | **≤ 24h** após qualificação completa |
| Taxa de perda por "desqualificação tardia" | **≤ 10%** (evitar erro de filtro) |
