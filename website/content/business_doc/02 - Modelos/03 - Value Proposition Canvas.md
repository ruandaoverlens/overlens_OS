# Value Proposition Canvas

## Este artefato não vive aqui. O Value Proposition Canvas da Overlens pertence ao Growth System.

Status: <dado q="E" nota="A construção acontece no Growth System." />

Esta página existe para registrar a decisão de arquitetura documental e, futuramente, guardar apenas o resumo executivo e o ponteiro. Ela não deve conter uma versão própria do canvas.

## Por que fica no Growth System

O Value Proposition Canvas existe na relação entre **um segmento específico de cliente** e **uma proposta específica de valor**. Não é um documento único da companhia; é um documento por segmento.

Como segmentos diferentes têm jobs diferentes, dores diferentes, ganhos diferentes e mensagens diferentes, o canvas precisa viver ao lado de persona, segmentação e Jobs To Be Done, que são responsabilidade do Growth System.

Manter uma cópia independente aqui criaria duas fontes de verdade sobre proposta de valor, que é exatamente o problema que a nova arquitetura de documentação existe para evitar.

## O mesmo vale para o Mapa de Empatia

**O Mapa de Empatia pertence exclusivamente ao Growth System.** Não deve existir versão dele no Business Document, nem resumo próprio.

Ele deve ser construído depois da revisão das personas, a partir de pesquisa, comportamento observado, entrevistas, dados e padrões recorrentes, nunca a partir de estereótipos.

## Pré-requisitos

1. **Redefinição de personas**: em aberto, será feita posteriormente. As personas atuais da base são anteriores a esta direção.
2. **Definição dos segmentos** por mentalidade e comportamento, não por profissão.
3. **Jobs To Be Done atualizados**: os existentes foram escritos sob o recorte anterior de público.
4. Só então o canvas por segmento.

## O que ficará nesta página

Quando o canvas principal existir:

- Um resumo executivo de uma página do canvas do segmento principal.
- O ponteiro para a versão completa no Growth System.
- A data da última revisão.

Nada além disso. Se esta página crescer, a arquitetura documental está sendo violada.
